The **Mingei Online Platform** utilizes **Semantic Web technologies** and an **ontology-driven architecture** to digitally preserve and present intangible and tangible **Cultural Heritage**, focusing specifically on traditional crafts. By structuring information around a central **narrative-centric model**, the system connects basic data entries and **historical events** into chronological **Fabulae**, which are then translated into diverse **Narration styles** and multimodal **Presentations** for various devices. Following a **Human-Centred Design** approach, the platform integrates with external knowledge bases like **Europeana** and provides robust **authoring tools** that allow domain experts and curators to collaboratively build, visualize, and share interactive cultural narratives.
