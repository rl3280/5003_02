### Represent a Phenomenon with Code and AI

This week’s project challenges you to observe a **real-world phenomenon** — and use AI + code to model it in some way. Your goal is not perfection, but thoughtful exploration.

#### Step 1: Choose a Phenomenon to Observe

It can be from daily life (e.g. morning routines, subway boarding behavior), digital contexts (e.g. app notification habits), or social systems (e.g. peer feedback in class).

#### Step 2: Practice Computational Thinking

    - Decompose the phenomenon into smaller parts

    - Identify any patterns or repeated behaviors

    - Abstract: Focus on the essential elements

    - Optionally define an algorithm (a repeatable process)

#### Step 3: Use AI to Support Your Thinking

Try using a tool like ChatGPT or this Custom GPT for CTLinks to an external site. to:

    - Generate a pseudocode model

    - Get feedback on your breakdown or abstractions

    - Explore how your phenomenon might be represented in code

#### Step 4: Represent in Code

Create a simple HTML/CSS/JS prototype (in Codepen or similar) that expresses part of the phenomenon:

    - Focus on representation, state, or interaction

    - It can be abstract (like a pulsing circle for “stress”) or literal (like a morning checklist)

#### Step 5: Submit

Submit a Google Doc link via Canvas with:

    - A brief description of your observed phenomenon

    - How you used AI (include any useful prompts/responses)

    - Screenshots or links to your design sketches and code

    - Reflections on how computational thinking helped you see or structure the phenomenon
